# Assets Directory

This directory contains all visual assets for the CashKit landing page.

## Quick Reference

### Current Structure:
- `logos/` - Brand logos and favicons
- `images/` - General images and graphics  
- `icons/` - UI icons and symbols
- `videos/` - Video content and thumbnails
- `testimonials/` - Customer photos and avatars
- `mockups/` - Product mockups and previews
- `backgrounds/` - Background images and textures

### Usage in Code:
```jsx
// Example usage
<img src="/assets/logos/cashkit-logo.png" alt="CashKit" />
<img src="/assets/testimonials/nicole-m.jpg" alt="Nicole M." />
<video poster="/assets/videos/hero-video-thumbnail.jpg">
  <source src="/assets/videos/hero-demo-video.mp4" type="video/mp4" />
</video>
```

See `ASSETS_NEEDED.md` in the root directory for complete requirements.
